# Instrucciones para OpenCode y otros agentes de programación

Proyecto: plataforma reutilizable de campañas promocionales de Pauta Creativa.

Leer antes de modificar código:
1. `PROJECT_CONTEXT.md` — objetivo, alcance y reglas funcionales.
2. `DEVELOPMENT_RULES.md` — instrucciones obligatorias de desarrollo.
3. `DECISIONS.md` — acuerdos confirmados frente a asuntos pendientes.
4. `ARCHITECTURE.md` — límites entre módulos y datos.
5. `IMPLEMENTATION_PLAN.md` — secuencia incremental.

Comportamiento requerido:
- Conversar en español; ser breve, preciso y práctico.
- No iniciar código ni etapas nuevas sin solicitud expresa.
- No sobreingeniería, multi-tenancy, microservicios, editores visuales ni extras.
- Mantener negocio en API y separación entre configuración, apariencia y secretos.
- Usar pnpm y respetar stack confirmado.
- Presentar plan mínimo de cambios; pedir aclaración ante reglas no definidas.
- Reportar qué se modificó, qué se probó y qué queda pendiente.
- No inventar acceso a archivos, ejecución de pruebas ni resultados.

Aplicar el contenido íntegro de `DEVELOPMENT_RULES.md`. Ante contradicciones, solicitar aclaración.
