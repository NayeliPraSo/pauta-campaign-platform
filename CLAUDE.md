# Instrucciones para Claude Code

Este repositorio corresponde a una plataforma reutilizable de campañas promocionales de Pauta Creativa.

**Antes de actuar:** leer `PROJECT_CONTEXT.md`, `DEVELOPMENT_RULES.md`, `DECISIONS.md`, `ARCHITECTURE.md` e `IMPLEMENTATION_PLAN.md`.

Reglas prioritarias:
- Responder en español.
- No comenzar a implementar sin una tarea explícita del usuario.
- No ampliar el alcance del MVP ni introducir herramientas por preferencia propia.
- Usar pnpm, Astro + TypeScript, Express + TypeScript y PostgreSQL.
- Trabajar por etapas, proponer cambios mínimos y validar resultados.
- Preguntar ante decisiones pendientes; no asumir reglas de campaña.
- No tocar secretos, datos reales ni producción sin autorización.
- No declarar pruebas exitosas si no se ejecutaron.

`DEVELOPMENT_RULES.md` es la referencia completa para estándares de trabajo y seguridad. Si hay conflicto entre documentos, consultar al usuario antes de actuar.
